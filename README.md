# NiCo Documentation

**NiCo (Niche Covariation)** is a computational framework for integrating **single-cell RNA sequencing (scRNA-seq)** and **spatial transcriptomics** data at single-cell resolution. NiCo enables the annotation of spatially resolved cells, prediction of cell–cell interactions within tissue niches, and analysis of gene covariation across cellular niches.

## ⚠️ Recommended Workflow for New Analyses

## About NiCo

NiCo integrates complementary information from scRNA-seq and spatial transcriptomics to characterize the cellular organization and molecular interactions within spatial tissue niches.

NiCo can be used to:

* 🧬 **Annotate spatial cells** using information derived from scRNA-seq
* 🤝 **Predict cell–cell interactions** within spatial niches
* 🔬 **Characterize niche-specific cellular composition**
* 📊 **Identify gene covariation patterns** within cellular niches
* 🧩 **Integrate single-cell and spatial transcriptomic data** for downstream biological interpretation
